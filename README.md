# SOLACC IT Club Community Projects

This is the primary repository for the South Louisiana Community College IT Club. We use this space to collaborate on software projects, build the club website, and help members get hands-on practice with version control.

---
## Projects (projects.md)

Ensure all previous, active, and planned projects are documented for employers and officers

---

## Getting Started

Follow these steps to set up the projects on your machine:

1. Clone the repository:
   * `git clone https://github.com/SOLACC-IT-Club/main-projects.git`

   * `cd main-projects`

3. Create a branch for your work:
   * `git checkout -b feature/your-feature-name`

4. Save and commit your changes:
   * `git add <filename>`
   
   * `git commit -m "Add short description of what you changed"`

5. Push your branch and open a Pull Request:
   * `git push origin feature/your-feature-name`

---

## How to Contribute

All SOLACC students are welcome to contribute, regardless of skill level. 

* If you are new to Git, look at the Issues tab for tasks labeled "good first issue".
* All Pull Requests require at least one review from an officer or peer before being merged into the main branch.
* If you run into issues, ask for help in the project channel on Discord or bring your laptop to our next meeting.
* Please follow official style guides for any software or pull requests. This includes the professional standard of the programming language as well as the club's rules.
