# SOLACC IT Club Projects Registry

This document tracks all software, hardware, and infrastructure projects managed by the South Louisiana Community College IT Club. It provides an overview of our history, current work, and future ideas for incoming members and officers.

---

## Active Projects

### Club Website
* Description: A custom web page built to showcase member portfolios, publish event announcements, and provide resources for IT and CS students.
* Tech Stack: HTML, CSS, JavaScript
* Lead: President Shae Nicholas Bergeron
* Status: Core UI layout in progress.
* How to Help: Check open issues for CSS styling, mobile responsiveness, and content writing for project pages. Any contributions will lead to accreditation.

## Past Projects

All past projects are free to improve upon through permission of the previous or current owner. 

### Custom PC Builds (Semesters 1 and 2)
* Description: Sourced, tested, and assembled two desktop computers from spare parts and past campus hardware donations.
* Category: Hardware / System Administration
* Outcome: Fully functional desktop systems currently used by the club for testing operating system deployments, hosting local scripts, and running workshops.
* Documentation: Component specs and assembly logs are saved in the club inventory archive.

### Fortune Teller Program
* Description: A terminal-based Python tool developed as an introductory codebase for new members learning software development concepts. Utilizing GttS and Vosk.
* Tech Stack: Python 3.14
* Lead: Shae Nicholas Bergeron and Luke Brinkhaus
* Status: Basic logic complete. Code is open source and we encourage changing the code.

## Proposing a New Project

Have an idea for a project? Bring it up at a weekly meeting or open a discussion thread in our communication channels. 

New projects need:
1. A brief outline of the goals and necessary tools.
2. A project lead willing to coordinate tasks.
3. A breakdown of small tasks so other members can participate.
4. Documentation of actions taken and highlights to publish to the club wiki.
